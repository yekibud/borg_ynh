## 💫 New features in 1.4.5~ynh4

### Retrieve backups from the config panel

The config panel of the app has a new **Restore backups** tab. Choose components (all are selected by default) and dates, then click *Retrieve backups*: every matching archive is copied to the local backups of YunoHost (**Backups > Local storage**), from where you restore it with the usual YunoHost workflow.

The *Last backups list* tab is gone; the same list now sits at the bottom of the new tab, under *All archives in the repository*.

The same can be done from the command line:

```bash
__INSTALL_DIR__/retrieve-backup list
__INSTALL_DIR__/retrieve-backup retrieve ARCHIVE_NAME
```

Nothing is restored automatically, and existing local backups are never overwritten.
